```shell
clear
```

```
reset
```
Сбросить текущий терминал

```shell
reset
```


```shell
history
```

### Linux

Получить информацию по дистрибутиву
```shell
lsb_release -a
```
или красивей
```shell
fasfetch
```
или тех. подробности
```shell
inxi -F
```
Системный монитор
```shell
htop
```
`Q`-выйти из `htop`

Получить t и CPU/GPU и скорость вращения Fan
```shell
sensors
```

```shell
id
```
Получить список групп, в которых числится текущий пользователь
```shell
group
```


### Софт

Показать календарь
```shell
cal
```
Получить дату и время
```shell
date
```
Получить содерж. текст. файла
```shell
cat имя_файла
```
Отредактировать текст. файл
```shell
nano имя файла
```
Сохранить `Ctrl+s`, выйти `Ctrl+X`

### Сеть

Получить имя компьютера
```shell
hostname
```

```shell
hostname -i
```


```shell
ifconfig
```
```shell
ip -c r
```
Пинг адреса
```shell
ping 8.8.8.8
```
```shell
ping ya.ru
```
Чтобы выйти из бесконечного пинга, выполните `Ctrl+C`

Выполните пинг указанное кол-во раз
```shell
ping -c 4 ya.ru
```
Получить ин-фу по указанному домену
```shell
whois ozon.ru
```
Получить список портов
```shell
netstart -an
```
Получить маршруты
```shell
route
```

### Управление комп-ом

Перезагрузка


```shell
sudo shutdown -r now
```
или
```shell
sudo systemctl reboot
```
Выключение
```shell
poweroff
```
или
```shell
sudo shutdown -p now
```
